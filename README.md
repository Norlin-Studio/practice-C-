# C++ 練習

儲存庫：https://github.com/Norlin-Studio/practice-C-

## 每天使用

開始寫之前先 Pull（提取）；寫完後儲存檔案、Commit（認可），再 Push（推送）。推送成功後，另一台電腦才能 Pull 到新內容。Git 不會自動同步尚未推送的修改。

## 筆電已有 C++ 資料夾

1. 保留原資料夾，先將本儲存庫 Clone 到新資料夾，例如 C++-sync。
2. 把原資料夾的 .cpp、.h 等原始碼複製進新資料夾；同名檔案先比較，不直接覆蓋。
3. 不要複製 .git、.vscode 或 .exe。
4. 檢查檔案後 Commit、Push，之後使用新的資料夾練習。

每台電腦需各自安裝 Git、VS Code、Microsoft C/C++ 擴充套件與編譯器。.vscode 是各電腦的本機設定，不同步；.exe 可以重新編譯，也不同步。
